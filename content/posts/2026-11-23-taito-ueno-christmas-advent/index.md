上野恩賜公園で、今年も「東京クリスマスアドベント」が開かれています。11月6日（金）に袴腰広場で始まり、18日（水）からは不忍池のほとりにも会場が広がりました。どちらも12月25日（金）までです。入場は無料で、買い物や散歩の合間に立ち寄りやすい催しです。

## ポイント・概要

| 項目 | 内容 |
|---|---|
| 期間（袴腰広場） | **2026年11月6日（金）〜12月25日（金）** |
| 期間（不忍池エリア） | **2026年11月18日（水）〜12月25日（金）** |
| 時間（袴腰広場） | 12:00〜23:00 |
| 時間（不忍池エリア） | 月〜木 15:00〜22:00、金・土・日・祝 12:00〜22:00 |
| 場所 | 上野恩賜公園（袴腰広場は西郷隆盛像の近く、不忍池エリアは池のほとり） |
| 料金 | 入場無料（ステージ観覧も無料） |
| 主催 | 一般社団法人上野観光連盟（企画・運営：第一通信社、サエキジャパン。協賛：au PAY） |

- **会場の様子**：飲食物や雑貨などを扱うお店、イルミネーション、クリスマスマーケットの雰囲気を楽しめると案内されています。袴腰広場ではライブなどのステージもあり、出演スケジュールは公式サイトに載っています。
- **限定マグ**：会場限定のマグカップがあり、ドリンクはマグで提供されます。マグがなくなったあとは紙コップになるとのことです。
- **ヒュッテと装飾**：エンジョイトーキョーの記事（2026年11月19日付）によると、袴腰広場には大きなサンタ像と10軒以上、不忍池エリアには20軒以上のヒュッテ（小屋）が並び、世界各地のサンタ像は合計100体以上とのことです。
- **クリスマスサーカス「AURA」**：同記事によると、11月27日から不忍池の特設会場で1日2公演の予定です。こちらは有料です。日程・料金・チケットは公式サイトでご確認ください。

## 街目線のひとこと・お出かけ前のチェックポイント

上野公園は、動物園や美術館へ向かう人、池のまわりを歩く人など、いつも少しずつ違う人の流れがある場所です。そこに赤と緑の小さな屋根が並ぶと、日が短くなったこの時期の夕方が、ちょっと楽しみな時間に変わります。

- **アクセス**：会場はJR上野駅から徒歩約2分と紹介されています（エンジョイトーキョー）。
- **曜日で時間が違います**：不忍池エリアは、月〜木は15時から開きます。お昼に行くなら金・土・日・祝が確実です。
- **雨の日**：雨天でも開催されますが、早く終了する場合があります。荒天時は中止になることもあり、最新情報は主催者がSNSで案内するとのことです。
- **ルール**：車両（バイク含む）は入場・駐車できません。席取り・場所取りも禁止です。
- **価格**：マグやフード、グッズの価格は公式サイトに載っていません。会場でご確認ください。
