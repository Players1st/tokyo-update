中野駅南口の再開発で道路の拡張が進むなか、一度は店を閉じた地元の酒場が戻ってきました。中野駅南口のファミリーロードに、「酒蔵いそむら」が11月10日に再オープンしています。仕事帰りに一杯、という日常の楽しみが、駅前の同じ場所で復活した形です。

## ポイント・概要

| 項目 | 内容 |
|---|---|
| 店名 | 酒蔵いそむら |
| 再オープン日 | **2026年11月10日** |
| 場所 | 中野区中野2丁目（中野駅南口・ファミリーロード） |
| 営業時間 | 17:00〜23:30 |
| 定休日 | 日曜・月曜 |
| 席数 | カウンター4席、テーブル16席（宴会場はありません） |
| 電話 | 03-3382-1381 |

- **休業の経緯**：中野駅南口の再開発に伴う道路拡張のため、約1年10カ月の休業を余儀なくされたと、中野経済新聞が伝えています。
- **お店の歴史**：同紙によると、1932年に鍋屋横丁付近で「鮨・割烹 三河屋」が開業しました。1966年に開業した酒蔵いそむらは、先代の跡を継いだ磯村泰司さんが店主を務めています。今年は60周年にあたります。
- **メニュー**：刺し身の盛り合わせや酒のさかな、料理のほか、おにぎりやお茶漬けなどの食事メニューがあります。お酒は日本酒、焼酎、泡盛、ビール、ハイボール、ワイン、ノンアルコール飲料が並びます。
- **お店の人の声**：女将の磯村知恵子さんは、急な建て替えでお客さんに十分な挨拶ができなかったことに触れ、60周年を迎えた今年の再開を語っています。

## 街目線のひとこと・お出かけ前のチェックポイント

再開発で駅前の景色が変わっていくなか、長年通った店が同じ駅の近くで灯りをともしてくれるのは、常連さんにとってうれしい知らせでしょう。〆におにぎりやお茶漬けを選べるのも、飲んだ帰りにはありがたいところです。

- **営業は夕方から**：17時開店です。ランチ営業については、記事では触れられていません。
- **定休日に注意**：日曜と月曜が休みです。
- **席数は多くありません**：カウンター4席とテーブル16席なので、グループで行くときや混み合う時間帯は、電話で確認してから行くと安心です。
- **料金・予約・最新の営業時間**：詳しくはお店にお問い合わせください。
